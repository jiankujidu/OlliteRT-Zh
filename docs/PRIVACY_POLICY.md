# 隐私政策

**生效日期**：2026-01-01
**适用应用**：一起瞎折腾（OlliteRT 中文版，包名 `com.ollitert.llm.server`）

---

## 概述

> **本应用完全本地运行，设计上不含任何云端推理、遥测、统计或账号体系。**
> 模型下载完成后，即使断开网络也可正常使用。

「一起瞎折腾」在你的 Android 设备上通过 Google LiteRT 运行时直接运行大语言模型（LLM）。
文本生成、图像理解、语音处理等全部计算都在手机本地的 GPU / CPU 上完成。

**你的提问内容、对话记录与 API 请求不会离开设备。** 它们仅在内存中处理，不会长期保存；
只有在你主动开启日志持久化时才会写入本机数据库，且同样只保存在手机本地。

---

## 网络连接

本应用仅在以下场景发起外网请求：

| 场景 | 触发时机 | 发送内容 | 可否关闭 |
| --- | --- | --- | --- |
| 下载模型 | 手动下载或首次导入模型清单时 | 模型文件下载请求（含 User-Agent） | 可（不下模型即不联网） |
| 刷新模型清单 | 模型管理页手动刷新 / 后台定期刷新 | 明文 GET 请求，不含设备身份信息 | 可（关闭自动刷新） |
| 检查版本更新 | 手动点击或开启自动检查时 | GitHub Release 接口的匿名 GET 请求 | 可（关闭自动检查） |
| 本地 API 服务 | 你在局域网内主动连接时 | 局域网内 HTTP 请求，不出网 | 可（不启动服务） |

除此之外，本应用不会向任何服务器发送你的个人信息。

模型清单请求默认经过第三方 GitHub 代理（如 `gh-proxy.com`）转发，以便国内网络可达；
该代理仅做静态文件转发，本应用不向它提交任何用户数据。

---

## 数据存储

所有数据保存在应用私有目录（Android 沙箱）内：

- **模型文件**：`/data/data/com.ollitert.llm.server/files/` 或你指定的共享存储目录
- **对话 / 请求日志**：本地数据库（Room），仅在开启日志持久化后写入
- **偏好设置**：DataStore 本地文件

卸载应用会一并清除上述全部数据。

---

## 权限说明

| 权限 | 用途 | 是否必需 |
| --- | --- | --- |
| `INTERNET` | 下载模型、刷新清单、检查更新 | 必需 |
| `POST_NOTIFICATIONS` | 显示下载进度与后台服务状态通知 | 可选（可拒绝） |
| `FOREGROUND_SERVICE` / `..._DATA_SYNC` | 保证长时间模型下载不被系统中断 | 必需（下载时） |
| `MANAGE_EXTERNAL_STORAGE`（可选申请） | 读取你放到共享目录里的模型文件 | 可选 |

本应用**不申请**通讯录、定位、通话记录、短信、相机、麦克风等无关权限。

---

## 第三方服务

- **Google LiteRT / MediaPipe**：本地推理运行时，不联网
- **Hugging Face**：模型文件下载来源，仅在你选择模型时访问
- **ModelScope（魔搭）**：国内镜像模型来源，清单内置，仅在你选择时访问
- **GitHub Releases**：版本更新检查与 APK 下载

以上第三方服务各自适用其自身的隐私政策，本应用无法控制其数据处理行为。

---

## 儿童隐私

本应用不面向 13 岁以下儿童，也不会有意收集儿童的个人信息。

## 政策变更

若隐私政策发生实质变更，会在本仓库与本应用 Release 说明中同步更新。
